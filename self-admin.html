Self-service settings — match your name and manage your own alerts.

Match Your In-Game Name

Search for your name in the alliance roster and pick it. This shows up automatically in admin — no more waiting on an officer to type it in for you. You can re-pick any time if you got it wrong.

WhatsApp Alert Buttons

Set up one-tap WhatsApp buttons that only alliance admins can see and use — for example, a button labelled "🚨 Raided" that opens a pre-filled WhatsApp message to you. Nobody else can see or press these, and admins get a confirmation prompt before anything opens, so it can't be triggered by accident.
How to build the link: Easiest way — go to create.wa.link, enter your number and a message, and it'll give you a short link like wa.link/abc123. Paste that link below.
