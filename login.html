Discord sign-in most often fails when it starts in one app/browser and finishes in another — the security check from step one isn't there anymore by the time it comes back. A few things that usually fix it:
  1. Stay in one browser the whole way through. Open the tracker in Chrome/Safari directly, then tap Sign in with Discord from there.
  2. Avoid Discord's built-in browser. If you tapped a link posted in Discord, it opens Discord's own in-app browser by default. Long-press the link (iOS) or use the "⋮" menu → "Open in Chrome/Safari" (Android) instead.
  3. Try Sign in with Google above instead — same result, doesn't have this problem.
  4. Use email sign-in below as a fallback — slower, but always works.
