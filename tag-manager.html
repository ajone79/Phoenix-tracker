Tag manager

Define the action-tag vocabulary and match it to events. Events sharing a tag on the same day can be completed together — the preview at the bottom shows which days stack.

Read-only

You're signed in but not a tracker admin, so you can view tags and matches but can't add or edit them.

Action tags

The vocabulary — grouped by family. A tag describes one underlying action (e.g. "kill a solo armada").

Match events to tags

Tap tags to toggle them on an event. An event can have more than one tag if it can be satisfied more than one way.

Live preview — current arc

Computed from the current arc's dates in events-data-tags.js and whatever matches are saved above.
